# 数据与来源
仓库仅含明确标记的合成例，不分发原企业新闻、受限制数据、授权快照、原模型私有输入或内部接口地址。
使用者提供有权使用的报道文本，记录来源URL、标题、发布时间、抓取时间与正文哈希；发布时间仅作程序元数据，不默认作为事件时间。
source编号应与正文范围对应，首末段偏移按Unicode字符位置。示例格式见examples/synthetic_case.json。
全文在使用者自己的数据目录保存，供审计回读；模型证据卡是可复现子集，不把外存全文当已提供模型证据。
真实基线由三个固定开发问题构成，涵盖主体归属、同文状态冲突、日期及缺失字段；不是泛化测试。原12篇证据资产及独立报告私有保留。本仓库不含公司的原文或个人数据。
