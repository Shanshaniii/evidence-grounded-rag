# Evidence-Grounded RAG / 证据溯源问答

V2.0 演示版：将原文、模型回答、程序定位、结构检查与独立语义复核分开记录。提供生产 r2.2 的 collector、诊断器、引用定位器和安全结果页，以及可运行的合成示例。默认离线、零模型调用、Python 3.10+ 仅标准库。

## V2 快速运行

```powershell
python v2/demo.py
python -m unittest discover -s v2/tests -v
```

打开 `outputs/v2/results.html`。页面包含一个待复核回答和一个错误引文被阻断的回答，可展开查看原答案、引用、程序定位与风险。两例均为虚构内容，不能计入模型准确率。结构和引用通过始终保留 `review_required`，不会自动标为可信。

校验自己的本地答案，输入格式参考 `v2/examples/synthetic_cases.json`：

```powershell
python v2/demo.py --input v2/examples/synthetic_cases.json --output outputs/custom
```

此入口从已提供答案构造明确标注的离线信封，运行生产 collector/diagnostics，再生成 JSON 与 HTML；它不证明原始网络响应真实，也不调用模型。完整原文可通过 `source_context.registry` 外置提供，程序元数据不充当模型看到的证据。不要将私有输入或生成输出提交到公共仓库。

## V2 实测与边界

私有开发批次 r2.2 / R4，2026-10-26 完成：8 次真实请求（1 烟测＋7 正式），通信完成 8/8；正式题机械检查干净 2/7，另 5/7 被阻断。2026-10-27 对七题原始请求、回答与证据进行独立回溯人工审查：核心必要结论 4/7，严格整答 1/7。**机械 2/7 与业务严格 1/7 是不同口径。** 公共包整理与回溯审核没有追加生成。

8 次原始记录求和：输入 15,948 token，输出 3,310 token，共 19,258；客户端 112.845 秒，原生推理记录 111.892 秒。金额未知。聚合见 `docs/evaluation-v2.json`；早期 enriched summary 的 117.85 秒与原始记录不符，此处采用原始求和。私有原文与回答不公开，因此用户不能只靠公共包复现这批业务分数；可以复现公开示例及检查器行为。

本版移植原有生产检查链，补齐便携依赖，提供 HTML 安全转义/CSP、冲突保留、日期角色、开工事件和伪造引用的回归控制。24 个 V2 离线测试通过；旧 demo 2 个测试通过。测试均不能代替模型泛化验证。版本清单见 `docs/version-v2.json`。

检查器依赖有限词法与规则，不能完整识别任意语义、主体或冲突。V2 公共入口只校验已提供答案；既有单次模型适配器保留在下方旧版入口，未声称与私有生产调度等价。独立审查还发现机械放行样本漏答必需日期比较，说明通过检查不等于回答完整。剩余缺陷包括自由文补年份、引用 ID 未闭合、发表元数据引文格式、缩略拼接引文、日期主张未引日期句及支持状态误判。严格口径要求所有必需子问、逐字引用、引用闭包、日期绑定与自由文一致性均通过。七题均为已知开发题，不能直接与旧版三题分数作提升比较；下一轮修复上述问题并增加独立评估集。

## 保留的 r6 演示与历史结果

旧版发布包含 r6 证据卡/schema 核心与便携脱敏 demo。私有生产实验曾独立评分：r5 严格 0/3 → r6 严格 2/3；这是另一批历史实验，不与 V2 的 7 题口径合并。

### r6 运行
Python 3.10+，仅标准库。
```powershell
python app.py
python -m unittest discover -s tests -v
python app.py --output outputs/demo.json
```
默认合成fixture，真实模型调用为0；不会下载、训练或启动模型。
可选单次真实调用，使用自己的既有Ollama实例：
```powershell
$env:OLLAMA_BASE_URL = "http://127.0.0.1:11434"
$env:OLLAMA_MODEL = "your-installed-model-tag"
python app.py --live --case path/to/authorized-case.json --output outputs/real.json
```
不包含私有连接配置。便携demo适配器只验证过本地fixture，不能冒称它等同私有环境中独审过的生产授窗sender。单请求无自动重试；发生超时先确认后端终止，再决定下一次调用。

## 功能及责任
- 源内短证据卡：按问题词法及首/末段选取，记录原文范围与字面日期；原文完整由使用者保存。
- 单一schema生成提示与验证器，避免隐藏限制；仅一份简短回答，不生成重复claim.text。
- 正文与标题命名空间分离，引用逐字回读；程序metadata与模型事件判断分开。
- 保留原回答，不自动改日期、替换引文或程序补正确答案；定位通过仍需独立语义审核。

## 真实结果与限制
固定三个开发问题、每版3正式＋1烟测、零重试。独立评分结果：

|指标|r5|r6|
|---|---:|---:|
|必要内容|3/9|6/9|
|严格业务通过|0/3|2/3|
|正式输入token|4880|4378|
|正式输出token|1584|1408|
|正式客户端总耗时|50.702秒|47.030秒|

D01主体与业务范围、D04月日及缺失信息通过；D02仍缺标题引用，并将两个官网版本及日期混作同项目冲突。原失败和旧分数保留，完整聚合见docs/evaluation.json。
r6同时改变了模型证据子集、回答职责与长度，属于组合干预；三个开发问题的小样本不支持泛化、保留测试通过或单组件因果结论。烟测加载成本另列，费用无可信依据为null。
此处保留的是 r6 历史结论；后续 V2 进展以本文开头与 `docs/evaluation-v2.json` 为准。
